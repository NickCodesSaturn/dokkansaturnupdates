# Dokkan Saturn Updates

Public update metadata for Dokkan Saturn.

Stable manifest:

`https://raw.githubusercontent.com/NickCodesSaturn/dokkansaturnupdates/main/stable/current.json`

Saturn verifies this manifest with Ed25519 and verifies downloaded packages with SHA-256 before activation.

The current 1.99.0 record is a signed bootstrap manifest. The first installable stable package will be published for Saturn 2.0.
